# Catálogo de productos con JDBC
Aplicación Java que consulta productos almacenados en PostgreSQL.
## Tecnologías- Java 17- PostgreSQL- JDBC- Gradle- IntelliJ IDEA
## Requisitos- JDK 17 o superior- PostgreSQL- Base de datos `laboratorio_git_jdbc`
## Configuración
Definir las variables `DB_URL`, `DB_USER` y `DB_PASSWORD`.
## Ejecución
### Windows
`gradlew.bat run --args="700"`
### macOS o Linux
`./gradlew run --args="700"`
## Base de datos
Ejecutar `database/crear_base.sql`.
